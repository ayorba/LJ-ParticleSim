## How to run your final project Dlang

I'm expecting anyone using 'Dlang' should be able to just run `dub` and perhaps some arguments.

## Build instructions

**Please edit here** otherwise if there are other instructions (e.g. `dub -- args``) that I should know about.

*edit here and add additional instructions if  you are building something for Blender3D for example*

Navigate to the `PSET` directory, in which there should be `dub.json` and `dub.selections.json`
Run `dub` with no arguments, producing `prog`.
Execute `prog` with `./prog`
